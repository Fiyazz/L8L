Three skills. One project you can show off.

The course starts from zero. You don't need to know anything about tech before you begin. Pick a card to see what's inside.

Web design

Plan and style web pages that look good on any phone. You'll learn how people really use a page, so yours are easy to use.

You'll learn

  • Layout
  • Colour
  • Fonts
  • How people use a page

Coding

Write the code that makes websites work. You tell the computer what to do, and it does it.

How it goes

  1. Start with one line of code
  2. Build up, a little at a time
  3. Finish with a full page you made yourself

Design thinking

A way to solve real problems. You understand the problem first, then you build.

How it goes

  1. Spot a problem around you
  2. Ask the people who have it
  3. Sketch your ideas
  4. Then build

Your own project

The course ends with something real that you made. It's yours to keep and to show.

How it goes

  1. Pick coding or design
  2. Build a real project
  3. Show your family, your school or a future employer

Try it now: change the code

Tap a yellow box and type your own words or colours. The page changes as you type. In the course you write code like this yourself, starting with one line.

my-page.html
<h1 style="color: ">
</h1>
<p></p>
<button style="background: ">
</button>

A colour can be a name like teal or gold, or a code like #2B2FA0.

Questions people ask

Tap a question to open it.

Is L8L really free?

Yes. The app and every lesson are free. Feedback from a mentor and a certificate are paid extras.

Do I need data or Wi-Fi?

Only once, to download the app. After that your lessons open with no data.

What do I need to start?

A phone. The course starts from zero, so you don't need a computer lab or any tech knowledge.

What if I don't have a phone?

Use L8L on the web at a cyber café or on any computer. You sign in with your Google account.

How long does the course take?

It's a 3-month course, and you learn at your own pace.

What will I have at the end?

A project you built yourself: a website or a design. You can also add a certificate, which is a paid extra.

When can I get L8L?

L8L is coming soon. Join the waitlist and we'll message you when it opens.

Who makes L8L?

Lustr8lab, a technology company in Lagos, Nigeria. We taught this course in a real classroom before putting it on a phone.

What does L8L mean?

Little Africa. We're building it for young people across the continent.
